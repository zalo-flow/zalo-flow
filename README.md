## What is collected

Nothing is collected from visitors by the maintainers. There is no code here to
run, no script, no analytics, no tracker and no redirect.

The only data available to us is the aggregate traffic count GitHub shows to
every repository owner: a per-day number of views and clones, plus the count of
distinct sources. We do not receive visitor identities, IP addresses or any other
identifier, and we make no attempt to obtain them.
